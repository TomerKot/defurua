# 🇩🇪 Deutsch für Ukrainer — Автоматизований Telegram-канал

Повністю автономний сервіс для щоденного вивчення німецької мови українцями з **нульовим бюджетом** ($0). Працює в хмарі за допомогою **GitHub Actions**, нейромережі **Google Gemini 3.8 Flash**, графічної бібліотеки **Pillow** та синтезу мови **gTTS**.

   - Преміальна графічна картка (1080×1080) з транскрипцією та артиклями + аудіо вимови.

2. ☕ **10:35 — «Жива розмовна фраза» (Umgangssprache)** *(тихий пост)*
   - Реальний вираз, який німці щодня використовують у кав'ярнях, транспорті, на роботі + картка та аудіо.

3. 🥪 **13:05 — «Типова помилка українців» (Typische Fehler)** *(тихий пост)*
   - Розбір поширених кальок з української, «хибних друзів перекладача» (*bekommen* vs *become*, *kennen* vs *wissen*, *kein* vs *nicht*) + картка та аудіо.

4. 🏙️ **15:35 — «Живий ситуативний діалог» (Praktischer Dialog)** *(тихий пост)*
   - Реальний міні-діалог в аптеці, пекарні, супермаркеті, у лікаря чи на пошті + словничок та аудіо.

5. ✉️ **18:05 — «Офіційний лист (Musterbrief) / Бюрократія»** *(тихий пост)*
   - Готовий шаблон листа для німецьких інстанцій (*Kündigung*, *Bürgeramt*, *Krankenkasse*, оренда) + юридичні лайфхаки та аудіо.

6. 🌙 **20:35 — «Вечірній Quiz-батл» (Telegram Poll)** *(зі звуком)*

## 🌟 Нові інтерактивні модулі

### 📱 1. Telegram Web App (GitHub Pages)
- **URL**: `https://tomerkot.github.io/defurua/`
- Інтерактивні 3D флеш-картки з анімацією перегортання.
- Озвучення слів у браузері через Web Speech API (німецький голос `de-DE`).
- Миттєвий пошук за базою вивчених слів та фільтрами (der, die, das, фрази).
- Вбудований тренажер-тест із підрахунком балів.

### 🤖 2. Персональний AI-репетитор в особистих повідомленнях (`bot_tutor.py`)
- Задавайте боту **@DeLernenUaBot** будь-які запитання щодо німецької мови.
- Бот детально пояснює граматику, перекладає фрази та **автоматично надсилає голосове повідомлення** з аудіовимовою!
- Команди в DM:
  - `/start` — головне меню та постійна кнопка меню WebApp.
  - `/quiz` — індивідуальне тестування з конфеті.
  - `/word` — випадкове слово з карткою та вимовою.
  - `/letter` — готовий шаблон листа.
  - `/webapp` — швидкий доступ до тренажера.

## 🛠️ Покрокове налаштування в GitHub

Щоб бот публікував пости безкоштовно та автоматично, потрібно налаштувати секрети та права доступу у вашому GitHub-репозиторії.

### Крок 1. Отримайте токен Telegram-бота
1. Відкрийте Telegram і знайдіть бота [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot` та дотримуйтесь інструкцій (введіть назву та юзернейм бота).
3. Збережіть отриманий токен (виглядатиме приблизно так: `7123456789:AAH...`).

### Крок 2. Налаштуйте Telegram-канал
1. Створіть новий публічний або приватний Telegram-канал (наприклад, `Німецька для українців`).
2. Додайте створеного бота в **Адміністратори** каналу з дозволом **«Публікувати повідомлення»** (Post messages).
3. Визначте ваш `CHAT_ID`:
   - Для публічного каналу це просто його юзернейм з `@` (наприклад, `@de_dlya_ukraintsiv`).
   - Для приватного каналу перешліть будь-яке повідомлення з каналу боту [@userinfobot](https://t.me/userinfobot) або [@JsonDumpBot](https://t.me/JsonDumpBot), щоб дізнатися ID (починається з `-100...`).

### Крок 3. Отримайте безкоштовний ключ Google Gemini API
1. Перейдіть на [Google AI Studio](https://aistudio.google.com/).
2. Увійдіть у свій Google-акаунт.
3. Натисніть **«Get API key»** -> **«Create API key in new project»**.
4. Скопіюйте створений ключ (починається на `AIzaSy...`).

### Крок 4. Додайте секрети в репозиторій GitHub
1. Відкрийте ваш репозиторій на GitHub.
2. Перейдіть у меню: **Settings** (Налаштування) -> у лівій колонці виберіть **Secrets and variables** -> **Actions**.
3. Натисніть кнопку **«New repository secret»** та додайте три секрети:
   - **`TELEGRAM_BOT_TOKEN`**: токен вашого бота від @BotFather.
   - **`TELEGRAM_CHAT_ID`**: юзернейм вашого каналу (наприклад, `@de_dlya_ukraintsiv`) або числовий ID.
   - **`GEMINI_API_KEY`**: ключ доступу від Google AI Studio.

### Крок 5. Увімкніть дозвіл на запис для GitHub Actions
Оскільки воркфлоу автоматично оновлює файл `history.json` після кожної публікації, GitHub Actions повинен мати дозвіл на запис у гілку:
1. У налаштуваннях репозиторію перейдіть у: **Settings** -> ліворуч **Actions** -> **General**.
2. Прокрутіть сторінку вниз до розділу **«Workflow permissions»**.
3. Виберіть пункт: **«Read and write permissions»** (Читання та запис).
4. Натисніть кнопку **«Save»** (Зберегти).

### Крок 6. Увімкніть Telegram Web App (GitHub Pages)
Щоб інтерактивний словник та картки відкривалися за посиланням `https://tomerkot.github.io/defurua/`:
1. У вашому репозиторії на GitHub відкрийте **Settings** -> ліворуч **Pages**.
2. У розділі **«Build and deployment»**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / папка: `/docs`
3. Натисніть кнопку **«Save»**. За 1-2 хвилини додаток стане доступним у всьому світі!

## 🧪 Як протестувати запуск просто зараз?

Не обов'язково чекати розкладу — ви можете запустити публікацію вручну в будь-який момент:
1. Перейдіть у вкладку **Actions** вашого репозиторію на GitHub.
2. У лівому списку виберіть воркфлоу **«Автоматична публікація уроків німецької мови»**.
3. Праворуч натисніть випадаюче меню **«Run workflow»** -> оберіть тип (наприклад, `morning` або `letter`) -> натисніть зелену кнопку **«Run workflow»**.
4. За 30–45 секунд у вашому Telegram-каналі з'явиться опублікований пост із карткою та аудіозаписом вимови!
