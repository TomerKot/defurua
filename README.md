# 🇩🇪 Deutsch für Ukrainer — Автоматизований Telegram-канал

Повністю автономний сервіс для щоденного вивчення німецької мови українцями з **нульовим бюджетом** ($0). Працює в хмарі за допомогою **GitHub Actions**, нейромережі **Google Gemini 1.5 Flash**, графічної бібліотеки **Pillow** та синтезу мови **gTTS**.

---

## 🚀 Що робить бот щодня о 09:00 за Києвом?

1. **Генерує навчальний контент** через Google Gemini API за рубрикатором для адаптації в Німеччині:
   - 🛒 **Понеділок**: Побут та щоденне життя (Alltag) — супермаркети, оренда житла, лікарі, аптеки.
   - 🧩 **Вівторок**: Граматика без нудоти (Grammatik) — артиклі (der/die/das), відмінки, порядок слів.
   - 💼 **Середа**: Робота та бюрократія (Bürokratie & Beruf) — Jobcenter, Bürgeramt, Krankenkasse, резюме.
   - 🗣️ **Четвер**: Розмовна мова та сленг (Umgangssprache) — реальна жива мова, якою говорять німці.
   - ⚠️ **П'ятниця**: Типові помилки українців (Typische Fehler) — хибні друзі перекладача, кальки.
   - 🇩🇪 **Субота**: Ідіоми та менталітет (Redewendungen & Kultur) — фразеологізми та звичаї.
   - 🎯 **Неділя**: Практика та міні-тест (Quiz) — інтерактивне закріплення знань.
2. **Створює брендовану картку (1080x1080)** з акцентом на артиклі, транскрипцією та прикладом у житті.
3. **Озвучує вимову німецькою мовою** через gTTS та публікує її як аудіоповідомлення.
4. **Контролює унікальність**: записує кожне опубліковане слово у `history.json` та автоматично комітить оновлення назад у репозиторій GitHub, тому дублікати виключені!

## 🛠️ Покрокове налаштування в GitHub

Щоб бот публікував пости безкоштовно та автоматично, потрібно налаштувати секрети та права доступу у вашому GitHub-репозиторії.

### Крок 1. Отримайте токен Telegram-бота
1. Відкрийте Telegram і знайдіть бота [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot` та дотримуйтесь інструкцій (введіть назву та юзернейм бота).
3. Збережіть отриманий токен (виглядатиме приблизно так: `7123456789:AAH...`).

### Крок 2. Налаштуйте Telegram-канал
1. Створіть новий публічний або приватний Telegram-канал (наприклад, `Німецька для українців`).
2. Додайте створеного бота в **Адміністратори** каналу з дозволом **«Публікувати повідомлення»** (Post messages).
3. Визначте ваш `CHAT_ID`:
   - Для публічного каналу це просто його юзернейм з `@` (наприклад, `@de_dlya_ukraintsiv`).
   - Для приватного каналу перешліть будь-яке повідомлення з каналу боту [@userinfobot](https://t.me/userinfobot) або [@JsonDumpBot](https://t.me/JsonDumpBot), щоб дізнатися ID (починається з `-100...`).

### Крок 3. Отримайте безкоштовний ключ Google Gemini API
1. Перейдіть на [Google AI Studio](https://aistudio.google.com/).
2. Увійдіть у свій Google-акаунт.
3. Натисніть **«Get API key»** -> **«Create API key in new project»**.
4. Скопіюйте створений ключ (починається на `AIzaSy...`).

### Крок 4. Додайте секрети в репозиторій GitHub
1. Відкрийте ваш репозиторій на GitHub.
2. Перейдіть у меню: **Settings** (Налаштування) -> у лівій колонці виберіть **Secrets and variables** -> **Actions**.
3. Натисніть кнопку **«New repository secret»** та додайте три секрети:
   - **`TELEGRAM_BOT_TOKEN`**: токен вашого бота від @BotFather.
   - **`TELEGRAM_CHAT_ID`**: юзернейм вашого каналу (наприклад, `@de_dlya_ukraintsiv`) або числовий ID.
   - **`GEMINI_API_KEY`**: ключ доступу від Google AI Studio.

### Крок 5. Увімкніть дозвіл на запис для GitHub Actions
Оскільки воркфлоу автоматично оновлює файл `history.json` після кожної публікації, GitHub Actions повинен мати дозвіл на запис у гілку:
1. У налаштуваннях репозиторію перейдіть у: **Settings** -> ліворуч **Actions** -> **General**.
2. Прокрутіть сторінку вниз до розділу **«Workflow permissions»**.
3. Виберіть пункт: **«Read and write permissions»** (Читання та запис).
4. Натисніть кнопку **«Save»** (Зберегти).

## 🧪 Як протестувати запуск просто зараз?

Не обов'язково чекати 09:00 ранку — ви можете запустити публікацію вручну в будь-який момент:
1. Перейдіть у вкладку **Actions** вашого репозиторію на GitHub.
2. У лівому списку виберіть воркфлоу **«Щоденна публікація уроку німецької мови»**.
3. Праворуч натисніть випадаюче меню **«Run workflow»** -> оберіть гілку `main` -> натисніть зелену кнопку **«Run workflow»**.
4. За 30–45 секунд у вашому Telegram-каналі з'явиться перша опублікована картка з текстом та аудіозаписом вимови!
